BARRO'S PIZZA CREATOR 1.6 — COMPLETE OFFLINE PORTABLE TOOLKIT

1. Extract this ZIP to a normal folder. Do not run it from inside the ZIP.
2. Double-click Barros_Pizza_Creator_Manager.exe or INSTALL_OFFLINE.cmd.
3. Select the folder containing Pizza Connection 3 - Pizza Creator.exe.
4. Choose VERIFY GAME, then INSTALL / REPAIR.
5. Choose LAUNCH GAME. Enter Bakehouse and press F10 if the Barro's tab is hidden.

The commercial Pizza Creator game is not included. This toolkit installs only the
Barro's add-on, verified BepInEx 5 x64 loader and private Python runtime. It refuses
unknown game assemblies. Repair preserves provider settings and user-created media.
Remove Add-on deletes Barro's files but keeps shared BepInEx unless the advanced
PowerShell uninstaller is explicitly given -RemoveSharedBepInEx.

Windows SmartScreen may say "Unknown publisher" because this community build does
not yet have a paid Authenticode certificate. Verify the published SHA-256 checksums.
