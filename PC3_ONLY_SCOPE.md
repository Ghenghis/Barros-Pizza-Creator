# PC3-Only Scope — Mandatory

This project is **exclusively** for **Pizza Connection 3** and **Pizza Connection 3 - Pizza Creator**, branded together as **Pizza Connection 3 / Barro's Pizza**.

## Allowed

- Pizza Connection 3 runtime, Unity data, assets, text, scenes, PathIDs and reverse engineering.
- Pizza Connection 3 - Pizza Creator runtime profile `creator-0.11.272`.
- Runtime Proof Studio profile `studio-1.11.403`.
- Barro's Pizza Creator, pizza-agent, Workbench, Runtime Proof Studio, Windows-MCP, image/JPEG/PNG/WebP generation and validation, GitHub/GitLab publication, and evidence capture that target PC3.

## Prohibited

- Pizza Connection 2.
- Fast Food Tycoon 2.
- Pizza Tycoon 2.
- PC2 assets, catalogs, formats, counts, tools, reverse-engineering conclusions, plans, contracts or evidence.
- Continuing any previously queued PC2 task.

If an agent encounters PC2 context, it must stop that task, leave PC2 files unchanged, label the work `out_of_scope`, and continue only with the equivalent PC3 / PC3 Pizza Creator task.

PC2 evidence can never satisfy a PC3 gate. The machine-readable source of truth is `contracts/pc3-only-scope.json`.
